# Karachi Eats Healthy

Landing website for a healthy meal-plan subscription service in Karachi (brand name: **KALO**).

Open `index.html` in a browser. It is one self-contained file with no build step.

## What's included
- Hero, how-it-works, and "why us" sections
- 5 plans: Balanced, Weight Loss, Muscle Gain, Low Carb, Diabetic-Friendly
- Plan builder with live PKR pricing (meals/day, snacks, days/week, plan length, spice level)
- Weekly menu of 25 desi dishes with calories and macros, tabs and filters
- Karachi delivery-area checker, reviews, app section, FAQ, WhatsApp button
- Sign-up modal (front-end only; not yet connected to a backend)

## Editing
- Prices: the `PRICE` object in the script
- Dishes: the `DISHES` array
- Delivery areas: `AREAS` and `SOON`
- Phone, WhatsApp number and email: footer and `.wa` link (placeholders)

## Hosting
Turn on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`) and the site goes live.
